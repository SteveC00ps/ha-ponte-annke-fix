# Annke Bridge for Home Assistant

A Home Assistant add-on that provides an RTSP stream for cameras connected to a wireless Annke NVR (Annke Sight / JuanVision) that does not natively support RTSP.

## Installation
1. Home Assistant → Settings → Add-ons → Add-on Store → ⋮ menu → **Repositories**
2. Add: `https://github.com/gian883/ha-ponte-annke`
3. Install **Ponte Annke**, configure the required options (NVR address, username, and password), and start the add-on.

Further details can be found in [ponte_annke/DOCS.md](ponte_annke/DOCS.md).
