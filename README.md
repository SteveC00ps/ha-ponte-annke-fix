# Ponte Annke per Home Assistant

App (componente aggiuntivo) di Home Assistant che porta in RTSP le telecamere di un NVR wireless Annke (Annke Sight / JuanVision) che non ha RTSP.

## Installazione
1. Home Assistant → Impostazioni → App → Negozio delle app → menu ⋮ → **Repository**
2. Aggiungi: `https://github.com/gian883/ha-ponte-annke`
3. Installa **Ponte Annke**, compila le opzioni (indirizzo, utente, password dell'NVR) e avvia.

Dettagli nel file [ponte_annke/DOCS.md](ponte_annke/DOCS.md).
